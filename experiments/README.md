# Research execution

The executable runner is `python -m sealed_telemetry.cli experiment --seed 2026 --trials 2 --output NEW_DIRECTORY`. Fifteen deterministic scenario definitions are randomized by seed. UUIDs and disposable secrets intentionally remain fresh, so sanitized event bytes are not bit-identical between runs. Labels are joined only after prediction, never supplied to the detector. Raw labels and reports are stored separately.

The committed local-smoke dataset contains 30 runs and eight detector/ablation outputs per run. It is a software smoke check with virtual event time, not a calibration or held-out AWS study. The reported local harness p50/p95 are actual elapsed wall times for the whole local run; they are not Lambda overhead or detection latency. AWS cost, cloud latency and invocation overhead remain null. Inconclusive attack runs count as false negatives in recall; inconclusive rate is also reported separately.

Baselines are explicit simple rules: app-only flags observed app failures; audit-only flags successful audit actions lacking invocation metadata; fixed-missing compares audit/intent counts; IBER uses the full state machine and integrity gate. Ablations remove deadlines, bindings, provider evidence, or integrity verification. These definitions need preregistration and stronger provider-specific calibration before claims of research superiority. The dataset includes ambiguous copied-ID replay and benign faults; no desired target is substituted for an observation.

For final evaluation: freeze independent calibration/test run sets, scenario seeds and versions; collect AWS source/receipt/decision and enforcement times; preserve CloudWatch billing duration and approved cost data separately; calculate rates, uncertainty, reconstruction, overhead and actual cost with denominators. scripts/calibrate.py converts independently collected benign delay arrays into policy settings. ReconciliationPolicy supplies these settings to the detector and activation timeout calculation. Never tune deadlines on held-out attack labels.
